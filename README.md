# make-knowledge-cards

## 1. 项目解决什么问题

读过的长文章、课程笔记、技术文档，过几天就只剩模糊印象——内容太长、重点分散，不适合复习。本项目提供一个开源 Skill，把一段文本自动提炼成 **5–8 张知识卡片**，每张卡片只讲一个独立知识点，方便快速回顾与自测。

与"自动摘要"类工具不同，本 Skill 遵循三条硬规则：**不编造原文没有的信息**、**卡片之间不重复**、**信息不足时宁少勿凑**（知识点不够 5 个就如实产出更少，0 个就不产出）。

## 2. 主要功能

- **两种输入**：用户直接粘贴的文本，或本地 `.md` / `.txt` 文件。
- **固定卡片结构**：每张卡片包含四个要素——标题 / 核心知识（一句话）/ 简明解释（2–4 句）/ 例子或自测问题。
- **质量优先的提炼**：识别定义、原理、因果、方法、关键事实；合并重复内容；剔除纯营销 / 宣传性表述。
- **数量自适应**：知识点充足产出 5–8 张；1–4 个时如实产出并说明；0 个时不产出任何卡片。
- **结果落盘**：卡片在对话中展示的同时，写入当前工作目录的 `knowledge-cards.md`（已存在则覆盖）。

**暂不支持**：网页 / URL 抓取、PDF 解析、Anki 导出（`.apkg` / 导入 CSV）、图形界面（GUI）。

## 3. 安装方法

本 Skill 为纯指令型（无脚本、无第三方依赖），只需复制文件：

```bash
# 用户级（所有项目可用）
cp -r skills/make-knowledge-cards/ ~/.workbuddy/skills/

# 或项目级（仅当前项目可用）
cp -r skills/make-knowledge-cards/ .workbuddy/skills/
```

可选：若通过 OpenAI Agents SDK / Responses API 接入，直接加载 `agents/openai.yaml` 作为智能体声明即可（其 `instructions_file` 指向 `SKILL.md`，`model` 字段可按环境替换）。

## 4. 使用方法

安装后在对话中直接触发，例如：

- "把这篇关于区块链的文章做成知识卡片"（粘贴正文）
- "读取 `notes/xxx.md`，提炼成复习卡片"（提供本地文件路径）

Skill 会按 `SKILL.md` 中的流程工作：识别知识点 → 去重合并 → 判定数量 → 生成卡片，并在产出前执行自检清单（四要素齐全、无重复、无编造、数量合理）。

## 5. 输入输出示例

**输入**（`tests/fixtures/blockchain.md`，约 600 字区块链科普文）：

> 区块链是一种分布式账本技术。它把数据打包成一个个"区块"……（正文省略）

**输出**（`tests/outputs/blockchain-cards.md`，节选）：

```markdown
## 卡片 1：区块链的定义
**核心知识：** 区块链是一种把数据打包成"区块"、并用密码学哈希按时间顺序
首尾相连形成"链"的分布式账本技术。
**简明解释：** 它通过哈希函数让每个区块都携带前一区块的指纹，从而把分散的
记录串成一条有序的链条。"分布式账本"意味着账本不是集中存放在一处，而是分散保存。
**例子 / 自测：** 自测：区块链名字里的"区块"和"链"分别指什么？

## 卡片 4：不可篡改性
**核心知识：** 因区块经哈希链接且含前区块哈希，篡改历史区块需重算其后所有
哈希并超过全网算力，经济上几乎不可行。
**例子 / 自测：** 自测：为什么"改一个历史区块"在区块链里几乎做不到？
```

**信息不足的输入**（`tests/fixtures/thin.txt`，一段产品营销文案）触发"不凑数"规则，输出：

```markdown
原文未提炼出可记忆的知识点，未强行产出卡片。
```

完整示例见 `tests/outputs/`（含技术科普、叙事性文章、信息不足短文三种类型的实测结果）。
